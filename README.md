# openDocx

A high-performance, real-time collaborative document editor inspired by Google Docs, built with **Next.js 15** and modern full-stack technologies.

The application allows multiple users to create and edit documents simultaneously, collaborate in real time, manage personal and organization-based workspaces, and use a wide range of rich-text formatting and document management features.

## ✨ Key Features

### 📝 Rich Text Editor

Built with **TipTap**, providing a powerful document editing experience with support for:

* Headings
* Lists
* Checklists
* Links
* Tables
* Image uploads
* Rich text formatting

### 🤝 Real-Time Collaboration

Powered by **Liveblocks**, enabling users to:

* Edit documents simultaneously
* See other users' cursors and presence
* Collaborate in real time
* Add and manage commenting threads

### 🔐 Authentication & Organizations

Secure authentication and user management powered by **Clerk**, including:

* User authentication
* Personal workspaces
* Organization-based workspaces
* Organization invitations and member management

### ⚡ Real-Time Database

Uses **Convex** for reactive backend functionality and real-time data synchronization, including:

* Document creation
* Document storage
* Document updates
* Document deletion
* Real-time data synchronization

### 📄 Document Templates

Includes a collection of pre-formatted templates to help users quickly create documents, such as:

* Business letters
* Resumes
* Project proposals
* Other productivity-focused document templates

### 🛠️ Document Controls

Provides useful document editing and management tools, including:

* Margin rulers
* Undo and redo history
* Document formatting controls
* Export to PDF
* Export to HTML
* Export to TXT
* Export to JSON

### 📱 Responsive Design

Built with **Tailwind CSS** and **Shadcn UI** to provide a clean, modern, and responsive interface across different screen sizes.

### 🐳 Dockerized

The application is containerized using **Docker**, making it easier to create a consistent and portable environment for development and deployment.
